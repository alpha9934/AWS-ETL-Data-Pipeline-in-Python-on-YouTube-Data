
# AWS-ETL-Data-Pipeline-in-Python-on-YouTube-Data:
This project is a data pipeline for securely managing and analyzing YouTube video data. It streamlines both structured and semi-structured information, such as video categories and trending metrics. The goal is to extract valuable insights and patterns.

Given that YouTube is one of the world's most-visited platforms, with over 2.6 billion monthly users, it's the ideal place for a data-driven advertising campaign. To succeed, your company must analyze a massive volume of YouTube data using various tools and metrics. This analysis will help answer crucial questions, such as how to categorize videos based on comments and statistics, and what factors determine a video's popularity.

<H3>AWS Python ETL Pipeline Project- Dataset Understanding:</H3>
This ETL project leverages a Kaggle dataset containing daily trending YouTube video data from various locations. The raw data for each region includes key metrics like video titles, views, likes, and comments. A separate JSON file provides a category_id for each region. The goal is to build a pipeline that can effectively extract, transform, and load this structured and semi-structured data for analysis.

# Big Data Project on AWS:

This repository contains a complete Big Data solution built on the Amazon Web Services (AWS) cloud platform. The project demonstrates the end-to-end process of building a data lake, designing an ETL pipeline, and performing data analysis to generate business intelligence dashboards.

# Tech Stack:
➔ Languages SQL, Python3

➔ Services AWS S3, AWS Glue, QuickSight, AWS Lambda, AWS Athena, AWS IAM


## Project Highlights:

This project showcases a complete Big Data solution on AWS:

* **Data Lake:** The data lake is built on **Amazon S3** to securely store structured and unstructured data.
* **ETL Pipeline:** The Extract, Transform, and Load (ETL) pipeline is designed and developed using **AWS Glue** with **Spark ETL Jobs** for scalable data processing.
* **Querying & Analytics:** Data is made available for analysis using **SparkSQL** and **Amazon Athena** for running standard SQL queries.
* **Business Intelligence:** **Amazon QuickSight** is used to create interactive BI dashboards, providing valuable insights from the processed data.
* **Monitoring:** The pipeline includes a monitoring solution using **Amazon SNS** for automated alerts and notifications.
